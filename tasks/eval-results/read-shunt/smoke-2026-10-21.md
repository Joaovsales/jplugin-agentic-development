## Where the runner leaves transcripts

With `--keep-temp` the run's temp home `<TEMP>/claude-eval-<id>/` holds two
records of the candidate:

- `out/trace.jsonl` — the `stream-json` event trace the runner names as
  `tracePath` in its JSON: `system` (hook events, `init`), `assistant`,
  `user` (with `tool_use_result` and `parent_tool_use_id`), `rate_limit_event`,
  `result`. Only the five message records carry timestamps.
- `config/projects/<encoded cwd>/<session>.jsonl` — the ordinary session
  transcript (`CLAUDE_CONFIG_DIR` points at `config/`), 41 lines here, the
  shape `read_transcript.py` pins; a sub-agent would sit beside it under
  `<session>/subagents/`.

Both grade. The session transcript is the one to arrange into the grader's
layout, because it is the shape the fixtures pin and the baseline measured.
Without `--keep-temp` the runner deletes both; the kept directory is
agent-written territory on Windows (modes cannot seal it), so the transcript
was copied out and the directory removed, as the runner asks.

## What a full run needs

- Drop `Bash` from `--allow-tools` on Windows, or run on a host with the
  sandbox backend; the large cases that expect `cat`/`sed` routing-around will
  show none of it without a shell.
- Two arms (control plugin, candidate plugin) each into their own results
  directory arm, `--runs ≥ 2` per case, every run under `--max-cost-usd`; at
  this case's cost one run of the suite is on the order of $2–5 before the
  large cases' longer sessions.
- `--keep-temp`, then copy each run's `config/projects/**/<session>.jsonl` (and
  its `subagents/`) into `<results>/<arm>/<task>/run-<n>/transcript.jsonl` with
  `outcome.json` from the runner's per-run score, and remove the temp homes.
