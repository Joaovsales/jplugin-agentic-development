¶ Summary

The suite is disciplined — most refusal tests pin exit code and message, most absence sweeps carry a positive control, fixtures are sandboxed — but the discipline lives in each file's head, not in the library. Ousterhout's diagnosis applies: lib.sh is a shallow module. It exposes nine string assertions and hides nothing else, so every one of 76 files re-derives the fixture lifecycle, the run-and-capture idiom, the exit-code check, the present/absent encoding and the positive control. Where a file forgot one, the suite has a hole, and five of five mutation probes the critic reasoned through survive today.

Behavior

tests/lib.sh becomes a deep module: a test file states what it checks and the library owns how — fixtures, capture, verdicts, counting, platform, and the string tests/affected.sh selects on. A file that forgets a discipline cannot create a hole, because the discipline is not in the file.

  • A test names the artefact it covers once, through under_test <repo-relative path>, which prints the absolute path and is the literal affected.sh matches (prefix match, so a directory covers its scripts). One mention serves both purposes, so they cannot drift.
  • A refusal is asserted in one call that owns exit code and reason: assert_refused <exit> <reason-fragment> -- cmd…. A reason fragment shorter than 6 characters is itself a failure.
  • An absence sweep runs through assert_sweep_empty <label> <control-file> -- grep-args…, which fails when a swept root is missing or the control does not match, then asserts empty.
  • finish fails a file with zero assertions unless the file called skip <reason>; skip counts, prints SKIP, and under REQUIRE_ALL=1 (set by tests.yml) fails the file. The silent half of F2 is gone; the loud half is visible in CI.
  • Every failure prints the first 20 lines of the actual value (truncated with a pointer, per § Large-Artifact Handoff) and ${BASH_SOURCE[1]}:${BASH_LINENO[0]}.
  • tests/expected-failures.txt lists <file> <platform-glob> <assertion message>; lib.sh loads the rows for $0 on the matching platform, prints XFAIL for a listed failure without counting it, and fails the file on XPASS so the list can only shrink. Linux CI loads no rows.
  • Fixtures come from two primitives, fixture_dir and fixture_repo, with one library-owned EXIT cleanup, identity written to .git/config, gpgsign and autocrlf off, and shared seed content copied from tests/fixtures/<area>/ through fixture_copy.
  • lib.sh exports LC_ALL=C and PYTHONDONTWRITEBYTECODE=1 beside PYTHONUTF8=1. run.sh wraps each file in timeout "${TEST_FILE_TIMEOUT:-300}". tests.yml sets TEST_JOBS=4 and REQUIRE_ALL=1.

Inputs

  • The 76 existing test files, migrated in place; no test is deleted for being prose-based unless F9's rule says its needle is not a contract.
  • tests/fixtures/ as the home for shared seed content.
  • The Windows baseline, captured once from a clean-HEAD run on the dev host into tests/expected-failures.txt with each row's cause from #129/#203/#269.

Outputs

  • tests/expected-failures.txt and XFAIL/XPASS/SKIP lines in the trailer.
  • Behavioural tests for session-stop.sh, cron-quiet-hours.sh, bootstrap-worktree.sh and the pre-push hook's blocking branches.

Edge Cases

  • A file whose every assertion is inside a loop that iterates zero times now fails at finish; that is the intended verdict (F2).
  • A pass-only file written for a smoke check must call skip or assert something; the migration audits each file whose count drops.
  • under_test with a path that does not exist fails the file at source time — a renamed script cannot silently drop a test from selection.
  • XPASS on a row whose cause was fixed upstream (#269 lands) fails the Windows run until the row is removed: deliberate, so the list reflects reality.
  • assert_refused on a command that prints the fragment and exits 0 fails on the exit half; one that exits non-zero for a different reason fails on the fragment half (closes F3 structurally).
  • cp -r of a template repo copies .git/index; a scenario that runs git status re-hashes, which is correct and cheaper than three spawns.
  • Parallel CI: every write already lands in a mktemp dir; __pycache__ is the one shared-tree hazard and PYTHONDONTWRITEBYTECODE=1 closes it.
  • A test file that migrates to the primitives but still names its artefact by a variable-built path is caught by its area slice's selection criterion, not by the suite-wide sweep: each area slice proves affected.sh selects its files on the artefact's path.
