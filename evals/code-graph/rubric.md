# Navigation outcomes

Written before any paid run. All wired graders are deterministic; this rubric
documents their interpretation and does not launch a paid judge.

- Localization: the final response names the responsible file and containing
  function, rather than only the entry point or the visible exception site.
- Callers and interface changes: the location is the remaining incompatible
  consumer, not the already-updated declaration.
- Controls: the response names the requested file and any declared function;
  the file grader also requires the requested edit or new function to exist.
- Evidence: outcomes come from retained runner records, tool adoption and
  resource metrics from transcripts. A claimed use is never a tool invocation.

The six-rule go decision is exclusively the frozen spec's rule, applied by
the shared code-graph grader. There is no subjective override or extra run to
cross a threshold.
